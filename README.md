Payroll Management System

Project Description

This project is a simple Employee Payroll Management System developed using Java.

The system is designed to manage different types of employees, calculate their salaries, taxes, and bonuses, and organize employee information.

Main Features

• Manage Full-Time Employees.
• Manage Contractor Employees.
• Calculate Gross Salary and Net Salary.
• Calculate 15% Tax.
• Calculate Employee Bonuses based on Performance Score.
• Sort Employees by Base Salary.
• Sort Employees by Joining Date.

Java Concepts Used

• Object-Oriented Programming (OOP).
• Abstract Classes.
• Interfaces.
• Inheritance.
• Polymorphism.
• Encapsulation.
• Comparable and Comparator.
• ArrayList and Collections.

Technologies

• Java
• NetBeans IDE
